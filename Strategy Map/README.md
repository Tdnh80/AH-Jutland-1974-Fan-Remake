# 日德兰搜索·接敌裁判工具 — 使用说明(v6)

这是给《日德兰(JUTLAND 1974)》兵棋的**搜索/接敌阶段**用的一个命令行小程序。
它替你管一件事:双方舰队在海图上各自机动,**什么时候、在哪里、谁和谁**进入了
互相能看见的距离(也就是"接敌")。你只要告诉它每支舰队怎么走,它就按 10 分钟
一拍往前推,一旦两边靠到视距以内,就停下来报告。

> 这是开发中的原型(v6)。现在能可靠完成的:搜索阶段的接敌判定、三层编组(舰队/小队/船)
> 与四种转向、`course` 排队转向(到格心才转)、导入真实战斗序列、接敌后状态机、存档回放。
> 联网有双盲裁判机原型(见第 8 节)。

---

## 1. 装好、跑起来

需要 Python 3.10 以上;画图要用到 `matplotlib`(不画图就不装也行)。

```bash
pip install matplotlib
python3 fleet_search.py
```

进去之后是一个一问一答的命令行,提示符长这样:

```
[T0 sub0 31/05/16 0000] >
```

方括号里依次是:**回合数 T0**、**小拍 sub0**、**日期时刻 DD/MM/YY HHMM**。
输入 `help` 看所有命令,`quit` 退出。

## 2. 先跑个例子建立印象

什么都不用懂,先打这一行:

```
demo 17
```

程序会随机摆两支舰队、让它们各自走、每回合存一张图(`demo_t00.png`、`demo_t01.png`……),
直到它们碰上为止。打开那些 PNG 翻一遍,你大概就明白这工具在干嘛了:
红色是英国(GB),蓝色是德国(GE),实线是走过的路,虚线是计划要走的路,
金色的 ✕ 是接敌发生的地方。

看完想自己摆,就往下读。

## 3. 几个基本概念

### 海图与坐标

海图是六角格。每个格子用**字母数字格名**表示:字母是行(A=第 1 行、B=第 2 行……),
数字是列。比如 `A13`、`Z5`、`M27`。

开发者也可以用内部的轴坐标 `q,r`,比如 `13,1` 就是 `A13`。

- 一个格子的"对边距离"(也就是它的宽)= **36000 码**,相邻两格中心也相距 36000 码。
- 六个方向和它们对坐标的影响:

  | 方向 | 含义 | q,r 怎么变 |
  |---|---|---|
  | `E`  | 右   | q+1 |
  | `W`  | 左   | q−1 |
  | `NE` | 右上 | q+1, r−1 |
  | `NW` | 左上 | r−1 |
  | `SE` | 右下 | r+1 |
  | `SW` | 左下 | q−1, r+1 |

  注意"左上—右下"这条斜线(NW↔SE)上 **q 不变、只有 r 变**,这是这套坐标的特点。

### 时间

- **1 回合 = 60 分钟**,是主时间单位。
- 1 回合分成 **6 个 10 分钟"小拍"(substep)**,程序在小拍这个精度上判接敌。
- **3 回合 = 一个规划周期**,一次 `schedule` 正好覆盖一个周期。
- 时刻按 `DD/MM/YY HHMM` 格式显示,历史纪元从 1916 年 5 月 31 日 0000 起算。
  用 `time 0530` 设置游戏开始时刻。

### 航速

只有三档,对应一个 3 回合周期内走几格:

| 航速 | 3 回合走 | 每格用时 |
|---|---|---|
| `12` kn | 2 格 | 30 分钟/格 |
| `18` kn | 3 格 | 20 分钟/格 |
| `24` kn | 4 格 | 15 分钟/格 |

### 舰队与船

- 一支**舰队(fleet)**是一组船,默认排成单纵阵(line-ahead),船距 500 码。
- 船自动命名 `舰队名-1`、`舰队名-2`……,`-1` 是排头(旗舰)。
- 转弯时是"鱼贯转向":后面的船沿旗舰走过的同一条线延迟跟上,队形顺着航迹自然弯过去。
- 每支舰队属于 `GB`(英)或 `GE`(德);只有英德之间才判接敌。

### 视距 / 接敌

- **视距**是一个"能看多远"的距离(半径),默认 **20000 码**,上限 **36000 码**(= 一格宽)。
- **接敌**:任意一艘英国船和任意一艘德国船的直线距离小于视距,就算接敌。

> **为什么视距圈画出来比一个格子还大?这是对的,不是 bug。**
> 视距是"半径"。半径 20000 码的圆,直径 40000 码,本来就比一格(36000)宽。
> 这恰恰是这个程序存在的理由:视距和格子差不多大,所以**"在不在同一格"根本不能拿来判接敌**——
> 同一格里的两条船最远能差 41000 多码而互相看不见;隔壁格的两条船贴着公共边却近在咫尺、能看见。
> 所以必须算真实距离,而不是数格子。

## 4. 命令详解

下面每条都给了语法和例子。`<>` 是你要填的,`[]` 是可选的。

### 建队、删队、看状态

**`new <名字> <GB|GE> <进场回合> <格名> <航向> <航速> <船数>`**
建一支舰队,单纵阵。`进场回合` 是它第几回合出现(一般填 `0`,表示一开始就在)。

```
new GB1 GB 0 A13 SE 18 4      # 英方 GB1,4 艘船,起点 A13,朝 SE,18 节,T0 进场
```

**`delete <名字>`** — 删掉一支舰队。

**`list`** — 列出所有舰队现在的位置、航向、航速、调度状态。

### 让舰队动起来

**`relocate <名字> <格名> <航向> <航速>`**
直接把舰队摆到某格中心,重设航向航速。会清掉它正在执行的计划。

**`course <名字> <航向> [航速]`**
改航向(可顺带改航速)。**不是原地立刻转**:舰队会先驶到当前航向**前方的下一个六角格中心**,
到了那里才转向(符合单纵阵鱼贯转向——后面的船也到同一个格心才依次跟转,不会提前乱拐)。
没到之前 `list` 会显示 `pending→<航向>`。再下一次 `course` 改回当前航向 = 取消这次排队。
**正在执行 `schedule` 时不能用**,要先 `clear`。

**`schedule <名字> <航速> <格名> <格名> ...`**
给一个 3 回合的行进计划。给的航路点个数要等于 `航速÷6`:**12 节给 2 个、18 节给 3 个、24 节给 4 个**。
相邻两个航路点必须是挨着的格子。可以中途拐弯,也允许掉头 180°。

```
schedule GB1 18 A14 B14 B15     # 18 节,依次经过这 3 格
schedule GE1 12 C10 C9          # 12 节,2 格
```

**`clear <名字>`** — 取消当前计划,舰队停在原地、保持现有航向航速。

**`randwalk <名字> [航速]`** — 自动生成一段随机走的 3 回合计划(偏向直行)。航速可省略(用当前的)。

### 队形

**`formation <名字> <ahead|abreast|echelon> [right|left] [absolute|relative] [角度]`**
设置舰队队形。`ahead` 单纵阵(默认)、`abreast` 横队、`echelon` 斜队。
`right/left` 表示展开方向;`absolute/relative` 表示布局方向是否跟随航向。

```
formation GB1 abreast right relative    # GB1 改横队,向右展开,跟随航向
formation GE1 echelon left absolute 45  # GE1 改 45° 斜队,左展,方向固定
```

### 导入真实编组、多分队

一支舰队其实可以由**多个小队(Formation/Division)**组成:整支舰队作为一个整体机动,
各小队按"相对舰队中心的位置"挂在周围(可设成跟随航向旋转,或地图方位固定)。

**`loadorder <GB|GE> <文件> [格名] [航速]`**
直接从战斗序列文件(`GBformation.txt` / `GEformation.txt`)导入整方编组。
GB 会建出 `GB BS`、`GB BCF` 两支舰队,GE 建出 `GE BS`、`GE SG`,各自下挂十几个小队。

```
loadorder GB GBformation.txt 0,0
loadorder GE GEformation.txt 20,0
plot order                       # 出编组校验图,每支舰队一个子图,一眼看对不对
```

**`add formation <舰队> <小队名> ships <n> [offset <..F/B> <..L/R>] [kind ...] [spacing ...] [deploy ...] [turning ...] [rel ...]`**
给舰队手动加一个小队。**`del formation <舰队> <小队名>`** 删一个;**`list formations <舰队>`** 列出。

### 推进时间

**`step`** — 往前推一个回合(60 分钟,6 个小拍)。每个小拍都逐船算英德距离,
一旦有任何一对小于视距,就停下报告(见第 5 节)。

### 存档 / 回放

**`save <文件>`** / **`load <文件>`** — 存档/读档(JSON)。存的内容包含完整的命令历史和每回合快照。

**`replay <回合数>`** — 把盘面恢复到日志里第 N 个回合快照(0 起)。方便回头看某一回合的状态。

```
save battle.json            # 存档
replay 5                    # 回到第 5 回合快照
list                        # 看当时的盘面
```

### 视距、时刻、画图

**`vis <码数>`** — 设视距(半径)。上限 36000,超了会被自动压回。
**`time <HHMM>`** — 设第 0 拍对应的时刻,比如 `time 0530`。
**`plot [文件名.png]`** — 把当前盘面画成 PNG(默认 `board.png`)。
**`plot order [文件名.png]`** — 编组校验图(每支舰队一个子图)。
**`plot closeup [文件名.png]`** — **接敌后**的局部放大图:只画接敌格及其邻格(默认 `closeup.png`,别名 `plot encounter`)。还没接敌时退化为全局图。
**`demo [种子] [回合数]`** — 一键随机演示,每回合存一帧。
**`help`** / **`quit`** — 帮助 / 退出。

## 5. 怎么读输出

### `list` 的一行

```
GB1          [GB] A14  9000 yd from centre → SE edge  course=SE speed=18kn ships=4 sched→B15 (6st)
^^^           ^^  ^^^  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^  ^^^^^^^^ ^^^^^^^^^ ^^^^^^^^ ^^^^^^^^^^^^^^^
舰队名        阵营  格名  微观位置:距格心多少码、朝哪条格边     航向      航速     船数     调度:终点+剩几个小拍
```

微观位置就是你要的"格边 + 到格心距离":这艘旗舰此刻在 `A14` 格里、距格心 9000 码、
偏向 SE 那条边。其他船按相对队形自己摆即可。

### 接敌报告

```
╔══ ENCOUNTER (pre-contact, frozen) ══
║  T0 sub4 31/05/16 0810   vis=20000 yd
contact1: GB1 ⟷ GE1
  GB1    B14  12000 yd from centre → NW edge
  GE1    B14  12000 yd from centre → SE edge
  closest pair now: 24000 yd (>= vis: clean state)
  [aux] projected contact 0810 (+3.3 min), dist = vis:
        GB1  B14  10000 yd from centre → NW edge
        GE1  B14  10000 yd from centre → SE edge
```

要点:

- **时刻定格在"接触前最后一个干净的 10 分钟拍"**(此刻双方还在视距外,`24000 ≥ 20000`)。
  程序不会让你看到"已经穿进去"的距离,而是停在刚要接触的那一拍。
- 只报**每支舰队中心(旗舰)的微观位置**,不逐船列配对——你按队形自己摆船。
- **`[aux]` 那段是辅助信息**:把这一拍和下一拍之间插值,算出距离正好等于视距的那一刻
  (`+3.3 分钟`)和位置,告诉你"再过 3.3 分钟就正式接触"。要用就用,不影响定格。

### 图(`plot` / `demo`)

| 元素 | 意思 |
|---|---|
| 灰色六边形 + 格名标注 | 海图格子 |
| **红色** | 英国 GB |
| **蓝色** | 德国 GE |
| 实线 | 已经走过的航迹 |
| 虚线 + ★ | 当前计划要走的路,★ 是计划终点 |
| 实心圆点 | 每艘船现在的位置 |
| 点状圆圈 | 每艘船的视距范围(所有船都画) |
| 金色 ✕ + CONTACT | 接敌位置(只在刚接敌那一帧出现) |

## 6. 完整示例

### 例 1:正面对冲

```
time 0530
vis 20000
new GB1 GB 0 A13 SE 18 4
new GE1 GE 0 C10 NW 18 3
schedule GB1 18 A14 B14 B15
schedule GE1 18 B12 B13 B14
step
step
step
```

两队都奔向同一格,会在 0810 左右报"接触前定格"。

### 例 2:随机演示

```
demo 17 30
```

随机摆位、随机走 30 回合(碰上就提前停),每回合一张 `demo_tNN.png`。

### 例 3:接敌后想接着推

```
step                        # 触发接敌、自动定格、计划被清空
list                        # 看双方现在停在哪
relocate GB1 B14 W 24       # 比如英方掉头西撤
relocate GE1 B14 E 18       # 德方东追
step
```

### 例 4:存档与回放

```
step                        # 打了几个回合
save battle.json            # 存档
replay 3                    # 回到第 3 回合状态
list                        # 看当时的情况
```

```
save game1.json
quit

python3 fleet_search.py
load game1.json
list
```

存的内容:所有舰队状态、当前小拍、视距、完整命令历史与回合快照。不含随机种子。
