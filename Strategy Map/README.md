# 日德兰搜索·接敌裁判工具 — 使用说明(v4)

这是给《日德兰(JUTLAND 1974)》兵棋的**搜索/接敌阶段**用的一个命令行小程序。
它替你管一件事:双方舰队在海图上各自机动,**什么时候、在哪里、谁和谁**进入了
互相能看见的距离(也就是"接敌")。你只要告诉它每支舰队怎么走,它就按 10 分钟
一拍往前推,一旦两边靠到视距以内,就停下来报告。

> 这是开发中的原型(v4)。队形细节、接敌之后的处理、联网,都还没做(见第 8 节)。
> 现在能可靠完成的,是"搜索阶段的接敌判定"。

---

## 1. 装好、跑起来

需要 Python 3.10 以上;画图要用到 `matplotlib`(不画图就不装也行)。

```bash
pip install matplotlib
python3 fleet_search.py
```

进去之后是一个一问一答的命令行,提示符长这样:

```
[0000 sub0] >
```

方括号里 `0000` 是当前时刻(24 小时制 HHMM),`sub0` 是第几个 10 分钟拍。
输入 `help` 看所有命令,`quit` 退出。

## 3. 几个基本概念

### 海图与坐标

海图是六角格。每个格子用一对整数 `q,r` 表示,叫**轴坐标**。

- 写法:逗号隔开、**中间不要空格**,比如 `0,0`、`3,-2`、`-1,5`。负数完全正常。
- 一个格子的"对边距离"(也就是它的宽)= **36000 码**,相邻两格中心也相距 36000 码。
- 六个方向和它们对坐标的影响:

  | 方向 | 含义 | q,r 怎么变 |
  |---|---|---|
  | `E`  | 右   | q+1 |
  | `W`  | 左   | q−1 |
  | `NE` | 右上 | q+1, r−1 |
  | `NW` | 左上 | r−1 |
  | `SE` | 右下 | r+1 |
  | `SW` | 左下 | q−1, r+1 |

  注意"左上—右下"这条斜线(NW↔SE)上 **q 不变、只有 r 变**,这是这套坐标的特点。

> 原点 `(0,0)` 目前是任意取的参考点,你给的初始位置都是相对它来的。
> 等确定了搜索图上哪个格当原点,改一处常量即可,不影响用法。

### 时间

- **1 回合 = 60 分钟**,是主时间单位。
- 1 回合分成 **6 个 10 分钟"小拍"(substep)**,程序在小拍这个精度上判接敌。
- **3 回合 = 一个规划周期**,一次 `schedule` 正好覆盖一个周期。
- 时刻按 24 小时制 HHMM 显示。默认从 `0000` 起算;想改用 `time 0530`。

### 航速

只有三档,对应一个 3 回合周期内走几格:

| 航速 | 3 回合走 | 每格用时 |
|---|---|---|
| `12` kn | 2 格 | 30 分钟/格 |
| `18` kn | 3 格 | 20 分钟/格 |
| `24` kn | 4 格 | 15 分钟/格 |

### 舰队与船

- 一支**舰队(fleet)**是一组船,排成单纵阵(line-ahead),默认船距 500 码。
- 船自动命名 `舰队名-1`、`舰队名-2`……,`-1` 是排头(旗舰)。
- 转弯时是"鱼贯转向":后面的船沿着旗舰走过的同一条线、延迟跟上,队形会顺着航迹自然弯过去。
- 每支舰队属于 `GB`(英)或 `GE`(德);只有英德之间才判接敌。

### 视距 / 接敌

- **视距**是一个"能看多远"的距离(半径),默认 **20000 码**,上限 **36000 码**(= 一格宽)。
- **接敌**:任意一艘英国船和任意一艘德国船的直线距离小于视距,就算接敌。

> **为什么视距圈画出来比一个格子还大?这是对的,不是 bug。**
> 视距是"半径"。半径 20000 码的圆,直径 40000 码,本来就比一格(36000)宽。
> 这恰恰是这个程序存在的理由:视距和格子差不多大,所以**"在不在同一格"根本不能拿来判接敌**——
> 同一格里的两条船最远能差 41000 多码而互相看不见;隔壁格的两条船贴着公共边却近在咫尺、能看见。
> 所以必须算真实距离,而不是数格子。

## 4. 命令详解

下面每条都给了语法和例子。`<>` 是你要填的,`[]` 是可选的。

### 建队、删队、看状态

**`new <名字> <GB|GE> <进场回合> <q,r> <航向> <航速> <船数>`**
建一支舰队,单纵阵。`进场回合`是它第几回合出现(一般填 `0`,表示一开始就在)。

```
new GB1 GB 0 0,0 SE 18 4      # 英方 GB1,4 艘船,起点 (0,0),朝 SE,18 节,T0 进场
```

**`delete <名字>`** — 删掉一支舰队。

**`list`** — 列出所有舰队现在的位置、航向、航速、调度状态。

### 让舰队动起来

**`relocate <名字> <q,r> <航向> <航速>`**
直接把舰队摆到某格中心,重设航向航速。会清掉它正在执行的计划。

**`course <名字> <航向> [航速]`**
原地改航向(可顺带改航速)。**正在执行 `schedule` 时不能用**,要先 `clear`。

**`schedule <名字> <航速> <q,r> <q,r> ...`**
给一个 3 回合的行进计划。给的航路点个数要等于 `航速÷6`:**12 节给 2 个、18 节给 3 个、24 节给 4 个**。
相邻两个航路点必须是挨着的格子。可以中途拐弯,也允许掉头 180°。

```
schedule GB1 18 0,1 1,1 1,2     # 18 节,依次经过这 3 格
schedule GE1 12 2,3 1,3         # 12 节,2 格
```

**`clear <名字>`** — 取消当前计划,舰队停在原地、保持现有航向航速。

**`randwalk <名字> [航速]`** — 自动生成一段随机走的 3 回合计划(偏向直行)。航速可省略(用当前的)。

### 推进时间

**`step`** — 往前推一个回合(60 分钟,6 个小拍)。每个小拍都逐船算英德距离,
一旦有任何一对小于视距,就停下报告(见第 5 节)。

### 视距、时刻、画图、存档

**`vis <码数>`** — 设视距(半径)。上限 36000,超了会被自动压回。
**`time <HHMM>`** — 设第 0 拍对应的时刻,比如 `time 0530`。
**`plot [文件名.png]`** — 把当前盘面画成 PNG(默认 `board.png`)。
**`demo [种子] [回合数]`** — 一键随机演示,每回合存一帧。
**`save <文件>`** / **`load <文件>`** — 存档/读档(JSON)。
**`help`** / **`quit`** — 帮助 / 退出。

## 5. 怎么读输出

### `list` 的一行

```
GB1          [GB] hex(1,1)  9000 yd from centre → SE edge  course=SE speed=18kn ships=4 sched→(1,2) (6st)
^^^           ^^  ^^^^^^^^^  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^  ^^^^^^^^ ^^^^^^^^^ ^^^^^^^^ ^^^^^^^^^^^^^^^^^
舰队名        阵营  在哪个格    微观位置:距格心多少码、朝哪条格边     航向      航速     船数     调度:终点+剩几个小拍
```

微观位置就是你要的"格边 + 到格心距离":这艘旗舰此刻在 `(1,1)` 格里、距格心 9000 码、
偏向 SE 那条边。其他船按相对队形自己摆即可。

### 接敌报告

```
╔══ ENCOUNTER (pre-contact, frozen) ══
║  0810   vis=20000 yd
contact1: GB1 ⟷ GE1
  GB1    hex(1,2)  12000 yd from centre → NW edge
  GE1    hex(1,2)  12000 yd from centre → SE edge
  closest pair now: 24000 yd (>= vis: clean state)
  [aux] projected contact 0810 (+3.3 min), dist = vis:
        GB1 hex(1,2)  10000 yd from centre → NW edge
        GE1 hex(1,2)  10000 yd from centre → SE edge
```

要点:

- **时刻定格在"接触前最后一个干净的 10 分钟拍"**(此刻双方还在视距外,`24000 ≥ 20000`)。
  程序不会让你看到"已经穿进去"的距离,而是停在刚要接触的那一拍。
- 只报**每支舰队中心(旗舰)的微观位置**,不逐船列配对——你按队形自己摆船。
- **`[aux]` 那段是辅助信息**:把这一拍和下一拍之间插值,算出距离正好等于视距的那一刻
  (`+3.3 分钟`)和位置,告诉你"再过 3.3 分钟就正式接触"。要用就用,不影响定格。

### 图(`plot` / `demo`)

| 元素 | 意思 |
|---|---|
| 灰色六边形 + `q,r` 标注 | 海图格子 |
| **红色** | 英国 GB |
| **蓝色** | 德国 GE |
| 实线 | 已经走过的航迹 |
| 虚线 + ★ | 当前计划要走的路,★ 是计划终点 |
| 实心圆点 | 每艘船现在的位置 |
| 点状圆圈 | 每艘船的视距范围(所有船都画) |
| 金色 ✕ + CONTACT | 接敌位置(只在刚接敌那一帧出现) |

## 6. 完整示例

### 例 1:正面对冲

```
time 0530
vis 20000
new GB1 GB 0 0,0 SE 18 4
new GE1 GE 0 2,4 NW 18 3
schedule GB1 18 0,1 1,1 1,2
schedule GE1 18 2,3 1,3 1,2
step
step
step
```

两队都奔向 `(1,2)`,会在 0810 左右报"接触前定格"。

### 例 2:随机演示

```
demo 17 30
```

随机摆位、随机走 30 回合(碰上就提前停),每回合一张 `demo_tNN.png`。

### 例 3:接敌后想接着推

```
step                     # 触发接敌、自动定格、计划被清空
list                     # 看双方现在停在哪
relocate GB1 1,2 W 24    # 比如英方掉头西撤
relocate GE1 1,2 E 18    # 德方东追
step
```

## 8. 现在还做不到 / 简化掉的

为了先跑通核心,下面这些暂时没做或做了简化。看你们需不需要再加:

| 项目 | 现状 |
|---|---|
| **队形**(单横、梯形等) | 只有单纵阵,船距固定 500 码。三态队形 + 转向时相对位置怎么变,待定 |
| **接敌之后** | 现在只是"定格 + 清空计划"。保持接触/脱离接触、对方进相邻格→进入战术阶段,这套状态机还没做 |
| **严格"先到格心再转向"** | 现在 `course` 改向是在当前位置即时生效;严格按"格边→格心→格边、到格心才转"的排队逻辑还没做 |
| **轻巡侦察幕** | 历史上靠它发现敌人。现在所有船统一视距,没有侦察幕、突破侦察幕 |
| **战斗** | 完全不在范围内,这工具只管"搜索到接敌"为止 |
| **海岸、雷区、陆地** | 不识别;格子边界外也算合法位置 |
| **任意航向 / 航速** | 只有 6 个方向、3 档速度 |
| **拆队 / 合队 / 新建分队** | 不支持,舰队组成固定 |

上面前三项(队形、接敌后状态机、严格转向)是下一版(v5)的重点,等补充资料后再做。

## 9. 给开发者的备注

- 坐标内部用 axial `(q,r)`,六方向邻居增量统一(无奇偶行之分),像素映射 `x = 36000·(q + r/2)`、`y = 36000·(√3/2)·r`。
- `(0,0)` 原点是任意参考,改 `hex_center_xy` 的偏移即可重定位。
- 接敌判定在 10 分钟小拍上离散采样;触发后回退到上一拍并对接触对做线性插值得到 `=vis` 时刻,这是有意为之(战术阶段步长本就是 10 分钟,不做连续 CPA)。
- 1 kn × 10 min = 333.33 码;`STEP_YARDS_PER_KNOT` 取此值,使 18 节恰好 6 拍走 1 格。
